# Absolute Cinema: E-Ticketing System

A Web-Based Movie Ticket Booking and Reservation Platform

## 1. Project Overview

The **Absolute Cinema: E-Ticketing System** is a web-based application designed to improve the process of booking and purchasing movie tickets online. It provides customers with a convenient way to browse movies, view screening schedules, select seats, process payments, and receive electronic tickets without visiting a physical cinema ticket counter.

The system aims to reduce long queues, minimize booking conflicts, improve seat availability updates, and support more efficient cinema operations.

One of its key features is **Absolute Showtime Notifications**, which provides customers with booking confirmations, showtime reminders, and schedule updates to help them stay informed about their reservations.

The system also includes an administrative dashboard that allows authorized cinema staff to manage movies, screening schedules, ticket prices, bookings, and sales records.

## 2. Project Purpose

The purpose of this project is to develop a user-friendly and efficient online movie ticket reservation system that improves the booking experience for customers and supports the daily operations of cinema management.

The system aims to address common problems associated with traditional ticketing processes, including:

- Long queues at cinema ticket counters
- Delayed seat availability updates
- Double-booking and reservation conflicts
- Time-consuming manual transactions
- Limited access to movie schedules and ticket information
- Inefficient booking and sales monitoring

## 3. Project Objectives

The project specifically aims to:

- Provide an accessible online movie ticket booking platform.
- Allow customers to browse movies and view screening schedules.
- Enable customers to select available seats.
- Reduce double-booking through seat availability validation.
- Support online payment processing.
- Generate electronic tickets after successful transactions.
- Provide automated booking confirmations and showtime notifications.
- Allow administrators to manage movies, schedules, ticket prices, and sales records.
- Improve the overall convenience, functionality, and efficiency of cinema ticketing services.

## 4. System Features

### Customer Features

- **Account Registration and Login** – Allows customers to create accounts and access the booking platform.
- **Movie Browsing** – Displays available movies and their information, including title, genre, duration, and schedules.
- **Schedule Selection** – Allows customers to choose their preferred movie screening.
- **Seat Selection** – Displays seat availability and allows customers to select available seats.
- **Online Payment** – Supports the available payment methods implemented in the system.
- **Electronic Ticket Generation** – Generates an electronic ticket containing relevant booking information after a successful transaction.
- **Absolute Showtime Notifications** – Provides booking confirmations, showtime reminders, and schedule change alerts.
- **Booking History** – Allows customers to review previous reservations and access their electronic tickets.

### Administrator Features

- **Admin Authentication** – Restricts administrative access to authorized personnel.
- **Movie Management** – Allows administrators to add, edit, and delete movie information.
- **Schedule Management** – Supports the management of movie screening schedules.
- **Ticket Price Management** – Allows administrators to update ticket prices.
- **Seat Availability Management** – Supports monitoring and updating seat information.
- **Booking Management** – Allows administrators to monitor customer reservations and transactions.
- **Sales Monitoring** – Provides access to booking records and sales information.
- **Audit Logs** – Records administrative activities for accountability and monitoring.
